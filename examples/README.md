# Examples

What the skills and templates produce. Everything here is synthetic. ExampleCo is invented, and no real company, candidate or employee appears.

Each example says how it was made:

- **Script output.** Produced by running a bundled script on a data file in the repository. The block is refreshed and checked by `python3 scripts/build_examples.py --check`, so it cannot drift from the code.
- **Written by hand.** Shows the format and the level of detail. It is not a recorded session.
