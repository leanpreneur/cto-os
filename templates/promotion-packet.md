Keep this packet private. It describes a person.

## The case in three sentences

What this person has done at the next level, over what period, and with what result.

## Evidence by axis

Use the [leveling ladder](leveling-ladder.md). For each axis, give the proposed level's sentence, then dated examples that meet it. An example has a date, what the person did, and the result.

| Axis | Proposed level expects | Dated evidence | Result | Meets it? |
| --- | --- | --- | --- | --- |
| Scope | | | | Yes, partly, no |
| Ambiguity | | | | |
| Delivery | | | | |
| Craft (managers: People and craft) | | | | |
| Influence | | | | |
| Engineering with AI | | | | |

A person needs the pattern, not every sentence. Mark where the pattern holds and where it does not.

## Sustained or once?

List the quarters in which the person did work at the proposed level, and name one example from each. A single large project is evidence of potential. Two quarters or more is evidence of the level.

## Peer input

Three to five people, at least one from another team. Ask each the same questions: what did this person own, how did they work with you, what would you want them to do differently. Attach the answers, or summarize them without names if the people were promised privacy.

## Gaps

What does not yet meet the proposed level, with the evidence that would close each gap?
