# DR-000: Short title in the form "Use X for Y"

| Field | Value |
| --- | --- |
| Status | Proposed, Accepted, Superseded by DR-nnn, or Rejected |
| Date | YYYY-MM-DD |
| Decision owner | Name |
| Consulted | Names or teams |
| Review date | When to revisit this decision |
| Reversibility | Easy, Costly or Irreversible |

## Context

What problem forces a decision now? State the facts: scale, constraints, deadlines, cost, risk, and what has already been tried. Two to five sentences.

## Options considered

| Option | Benefits | Costs and risks | Estimated effort |
| --- | --- | --- | --- |
| A | | | |
| B | | | |
| C (do nothing) | | | |

## Decision

State the choice in one sentence, then the main reason in one sentence.

## Consequences

- What becomes easier.
- What becomes harder.
- What we now depend on.
- What we will measure to know the decision was right.

## Exit plan

What signal tells us to reverse this, and what would reversal cost?

## Notes

Links to design documents, benchmarks, vendor quotes and meeting notes.
